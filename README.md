# Rock Paper Scissors

A simple version of the classic game written in JavaScript and played via the CLI.

To install: 
- Clone the GitHub repo, change to the directory, and install dependencies using `npm i`

To run:
1. Once in the game directory, run `node game.js`
2. Enter a valid option from rock, paper, or scissors.
3. Type `quit` to exit.

Future features:
- Round tracking.
- Select from list of options instead of typing.
- Create a web version using HTML.
